# Showcase Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a responsive showcase for all 50 WooSign component modules.

**Architecture:** A standalone site directory uses Vite with the library source
alias and web extensions. A catalog drives gallery, demos, props and code snippets.
Hash routing preserves static-host deep links. Shared site chrome handles theme
and navigation, while examples are rendered inside the library's providers.

**Tech Stack:** React, TypeScript, Vite, existing Jest/testing-library.

1. Add site/vite.config.ts, tsconfig.json, index.html, favicon, scripts and ignore rules.
2. Add site/src/catalog.ts, demos.tsx and prop metadata from source types.
3. Build site/src/App.tsx and styles.css: home, gallery, detail, tokens and guides.
4. Test catalog coverage and real demo rendering, routing, filtering, state controls,
   theme persistence and copy-code fallback using site/jest.config.cjs.
5. Typecheck and build site; run existing library tests to ensure isolation.
6. Document local commands and static hosting. Prepare a reviewable local preview.
